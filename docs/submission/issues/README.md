# Contributor issue drafts

Nine existing repository drafts copied for human review, three per contract.
Each describes a concrete gap, scope, acceptance criteria, source entrypoints
and test commands. They remain unpublished. Recheck against the final source
before opening an issue; omit any feature already implemented or duplicated.

Do not publish these as artificial activity or claim that drafts are open issues.
Difficulty and labels are proposals; maintainers should calibrate them. New
dependencies and metadata/storage policy need a recorded technical decision.
