# Synthetic testnet demonstration authorization

On October 8, 2026, the maintainer explicitly confirmed deployment of SchoolFees,
EventBadges and InvoicePay to Stellar testnet as demonstrations using made-up
data. This authorizes the assistant to create a dedicated testnet identity,
deploy the three implemented contracts, initialize SchoolFees, verify the public
results and record addresses and explorer links.

This is a narrow exception to the existing partner-before-deployment and
human-only deployment instructions for these demonstrations. Real-pilot gates
remain in effect. No partner agreement, real pilot, security audit, mainnet
deployment or production readiness is implied. Use synthetic values only and
keep signing material outside repositories and outputs.
