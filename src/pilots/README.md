# Pilots

**No pilot has happened yet.**

This directory holds one file per **real** pilot, named after the participating
school or tutorial centre, in the shape `pilots/{name}.md`. It is empty because
nothing has happened: no school or centre has been named here, no pilot has run,
and no result has been recorded.

A pilot file is written **after** a pilot, from what actually happened. The
[rules in `AGENTS.md`](https://github.com/stellar-schoolfees/schoolfees-docs/blob/main/AGENTS.md)
are explicit: never invent testers, schools, quotes or outcomes, and never name
a participant more specifically than they agreed to. Nothing is added here on
the strength of an interested conversation — an interested person is not a
completed pilot, and an agreement to try is not a pilot either.

Two things must be true before the first file appears here:

1. A real school or tutorial centre has agreed to try the flow. That agreement
   is what unlocks the first testnet deployment.
2. Someone actually ran the flow, and the record can be written from those real
   transactions.

The process that leads up to a pilot is in the
[pilot playbook](../pilot-playbook.md), and the outreach message the maintainer
can adapt to recruit a school is in [pilot outreach](../pilot-outreach.md) —
a template only, which becomes a record of nothing until an agreement exists.
What a pilot can and cannot prove is in
[known limitations](../limitations.md).
